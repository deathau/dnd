# Block and Tackle

_Adventuring gear_

- **Cost**: 1 gp
- **Weight**: 5.0 lbs.

A set of pulleys with a cable threaded through them and a hook to attach to objects, a block and tackle allows you to hoist up to four times the weight you can normally lift.

_Source: Player's Handbook p. 151. Available in the <span title='Systems Reference Document (5.1)'>SRD</span> and the Basic Rules (2014)_
